# 🚀 My 25-Week Python & DevOps Engineer Roadmap

My goal is to become a Junior DevOps Engineer by learning Python, DSA, Linux, backend development, Docker, CI/CD, AWS, Terraform and Kubernetes through practical projects.

**Duration:** 25 Weeks  
**Daily Study Time:** 1.5–2 Hours  
**Primary Goal:** DevOps Engineer  
**Language:** Python

## 📊 Roadmap Progress

- [ ] Phase 1: Python Fundamentals & DSA
- [ ] Phase 2: Linux, Networking & Automation
- [ ] Phase 3: FastAPI, Django & Databases
- [ ] Phase 4: Docker, CI/CD & AWS
- [ ] Phase 5: Terraform, Kubernetes & Monitoring
- [ ] Phase 6: Capstone Project & Job Preparation

---

## 🐍 Phase 1: Python & DSA (Weeks 1–5)

- [ ] Week 1: Python variables, data types and operators
- [ ] Week 2: Conditions, loops and functions
- [ ] Week 3: Lists, strings, sets and dictionaries
- [ ] Week 4: OOP, files, exceptions and modules
- [ ] Week 5: DSA, arrays, searching, sorting and complexity

**Project:** Python fundamentals and DSA practice collection.

- [ ] Week 6: Linux commands and filesystem

- [ ] Week 9: Bash scripting and automated backups
- [ ] Week 10: Python automation and logging

**Project:** Server health checker and backup scripts.

## ⚡ Phase 3: Backend Development (Weeks 11–14)

- [ ] Week 11: FastAPI routes, requests and validation
- [ ] Week 12: FastAPI, SQLAlchemy and PostgreSQL
- [ ] Week 13: Django, models, views and ORM
- [ ] Week 14: Django REST Framework and API testing

**Projects:** FastAPI Task Manager API and Django REST API.

## 🐳 Phase 4: Docker, CI/CD & Cloud (Weeks 15–19)

- [ ] Week 15: Docker images, containers and Dockerfiles
- [ ] Week 16: Docker Compose and databases
- [ ] Week 17: pytest and GitHub Actions CI/CD
- [ ] Week 18: AWS IAM, EC2, S3 and VPC fundamentals
- [ ] Week 19: Deploy a Dockerized application to a cloud VM

**Project:** Automated build, test and deployment pipeline.

## 🏗️ Phase 5: Infrastructure & Monitoring (Weeks 20–23)

- [ ] Week 20: Terraform and Infrastructure as Code
- [ ] Week 21: Kubernetes Pods, Deployments and Services

- [ ] Week 23: Prometheus, Grafana, logging and security

**Project:** Kubernetes deployment and monitoring lab.

## 🎯 Phase 6: Capstone & Job Preparation (Weeks 24–25)

- [ ] Week 24: End-to-end DevOps capstone project
- [ ] Week 25: Revision, documentation and interview preparation

**Final Goal:** A documented DevOps portfolio with working projects.
